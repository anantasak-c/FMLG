# FLUX.3 three-tier generation

Status: superseded by ADR 0033

The customer pilot will use FLUX.3 for every video outcome: Economy Generation uses FLUX.3 Draft, High Quality uses FLUX.3 Video, and 2K Upscale uses FLUX.3 Video Upscaler. Draft is a selectable low-cost output tier rather than a compulsory stage; 2K Upscale remains a post-generation operation because it requires a completed source video.
