# Free Interactive Chat with Paid Output Model for AI Coach

## Context
AI Coach engages users in iterative conversations to refine prompt ideas. Charging users per chat message introduces anxiety and reduces conversation depth, while generating fully formatted model-specific prompts and storyboards represents tangible value.

## Decision
Conversational interactions with AI Coach remain free. Coins are deducted only when users trigger value-added output actions:
- `Final Prompt Generation` (5 Coins)
- `Model-Optimized Advanced Prompt` (10 Coins)
- `Multi-Shot Storyboard Pack` (15 Coins)

## Rationale
- Eliminates chat friction and encourages users to give thorough creative details.
- Clearly anchors the perceived value of Coin expenditure to concrete deliverables.
