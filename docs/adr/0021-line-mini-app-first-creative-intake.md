# LINE MINI App-first creative intake with desktop advanced Studio

Status: superseded by ADR-0025

FOMOlogy will use the LINE MINI App as the primary entry point for Thai beginner creators: they select a familiar video goal, complete an AI Coach interview one question at a time, preview a Prompt Package for free, and export a Studio Draft only when ready. The desktop Video Studio remains the advanced workspace for detailed settings and live monitoring. This supersedes the desktop-first entry assumption in ADR 0012 because the primary audience values low-friction LINE access and plain-language guidance more than professional controls at the start of the journey.
