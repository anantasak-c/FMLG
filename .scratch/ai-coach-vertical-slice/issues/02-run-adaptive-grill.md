# 02: Run the Adaptive Grill

**What to build:** A visitor can progress from a Guest Coach Session through a deterministic Adaptive Grill, receive at most three high-impact Thai questions per round, and review/edit a Thai Creative Brief summary before export.

**Blocked by:** 01: Start a Guest Coach Session.

**Status:** completed

- [x] The Grill selects unanswered decisions in the agreed priority order and never asks more than three questions in a round.
- [x] Each response updates the Creative Brief and produces a Thai summary of locked constraints.
- [x] Ambiguous format and over-dense timeline requests receive clear challenge questions rather than hidden assumptions.
- [x] The user can edit the final Thai Creative Brief summary and explicitly confirm it for export.
- [x] Automated behavioral tests cover question limits, priority, brief updates, summaries, and confirmation.
