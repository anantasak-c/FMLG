# 01: Start a Guest Coach Session

**What to build:** A Thai-first, approachable AI Coach entry flow where a visitor describes an idea in a short intake form and begins a Guest Coach Session. The visitor can change the current Creative Brief during the browser session without needing to understand video-model terminology.

**Blocked by:** None (can start immediately).

**Status:** completed

- [x] A visitor can enter a free-text idea, duration, aspect ratio, reference assets, format/era, and safety boundary using plain Thai labels.
- [x] Provider-specific and negative-constraint settings are hidden under an optional advanced area, with safe defaults for the Kling Provider Profile.
- [x] The form creates and updates a browser-session Creative Brief without a persistent user-owned record.
- [x] The UI follows the project light-first theme, supports the dark toggle, and is usable without prompt-engineering knowledge.
- [x] Automated behavioral tests demonstrate starting, editing, and retaining a Guest Coach Session in the browser session.
